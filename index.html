Review scheduler

Every professor listed below sees every team exactly once. Each professor can have their own start time, review length, and slot sizes (e.g. mostly solo, with a grouped final slot) — the engine finds a conflict-free arrangement automatically.

Day setup

Leave 0 for auto (at least one full review's worth of buffer, protects against a professor running late). Only matters with 2+ professors.
–
Slots never run across the break: they resume after it. To add afternoon sessions, just set a professor's start time after the break (e.g. 14:15), or give a morning professor more slots.

Teams and criterion

Topic is a standing attribute per team (set it once below — it's reused every time). "Priority this time" is a direct override: a team set to prefer early/late will reliably get that end of the schedule, regardless of criterion. "History (avg position)" is computed automatically from imported past schedules below and gives a gentle nudge only — it never overrides priority.
